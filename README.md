# O Freguês — conceito de experiência digital

Prévia independente, estática e mobile-first para apresentar uma alternativa complementar ao PDF enviado pelo restaurante. Inclui página de apresentação, navegação por categorias, informações da casa, mapa incorporado e link de rota.

- Abrir: `index.html`
- Prancha: `arte/index.html`
- Brief e limites factuais: `BRIEF_DO_PROJETO.md`

Imagens são referências visuais obtidas em publicações públicas do Instagram `@ofreguesgma`; precisam de autorização para uso em produção. O conteúdo integral do PDF de outubro/2026 ainda não foi extraído nesta sessão. Valores, disponibilidade, horário e composição devem ser validados com o restaurante.
